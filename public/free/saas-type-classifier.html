Question 01 / 03
Q1

What kind of problem does your SaaS solve?

Pick the answer that best describes the core job your product does for users.

A
Automates a simple, repetitive task

e.g. scheduling, reminders, basic data entry, simple form workflows

No-code territory +1 pt
B
Connects two or more existing tools or data sources

e.g. syncing CRMs, aggregating reports, managing multiple platforms in one place

Hybrid, some dev needed +2 pts
C
Processes, analyses, or transforms complex data

e.g. custom algorithms, AI features, real-time data, financial calculations

Custom build likely needed +3 pts
D
Enables real-time collaboration or multi-user interactions

e.g. shared workspaces, live editing, role-based permissions, team dashboards

Full custom build required +4 pts
Insider Note If you're torn between B and C, always score higher. Underestimating complexity is the #1 reason SaaS projects run over budget and over time.
Question 02 / 03
Q2

Who are your first 100 users and how will you reach them?

Your distribution method affects your tech requirements more than you think.

A
I'll sell directly to people I already know

Existing network, warm outreach, LinkedIn, local business community

Simple auth + payments enough +1 pt
B
I'll build an audience on social and convert them

Instagram, TikTok, YouTube, Twitter/X: inbound marketing funnel

Landing page + email capture +2 pts
C
I'll use SEO, ads, or a marketplace to drive traffic

Google Ads, App Store, ProductHunt, affiliate partnerships

Analytics + tracking needed +3 pts
D
I'll sell B2B with demos, contracts, and a sales process

Sales team, demo calls, custom contracts, SSO, compliance requirements

Custom build, no shortcuts +4 pts
Insider Note B2B enterprise sales (option D) almost always requires custom development. Compliance and security requirements alone rule out most no-code tools.
Question 03 / 03
Q3

What does your MVP need to do on day one?

Be honest. What is the absolute minimum feature set to charge your first customer?

A
Show, collect, or display information in a structured way

Dashboards, directories, databases, simple portals, content platforms

Airtable + Softr can handle this +1 pt
B
Let users log in, manage their account, and see their own data

User profiles, settings, saved items, personalised views

Auth library + basic backend +2 pts
C
Integrate with one or more third-party APIs

Stripe payments, Twilio SMS, Google Maps, OpenAI, Slack webhooks

Dev required for API work +3 pts
D
Run complex logic, calculations, or real-time processing

Custom pricing engines, matching algorithms, live notifications, AI pipelines

Fully custom, significant dev time +4 pts
Insider Note API integrations (option C) are where no-code tools break down most often. If your core value prop requires an external API, budget for a developer from day one.
